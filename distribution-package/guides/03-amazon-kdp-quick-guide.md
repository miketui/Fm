## Quick Start Steps

### 1. Convert EPUB to Kindle Format ⚠️

**Option A: Kindle Create (Recommended for Beginners)**
1. Download: https://kdp.amazon.com/en_US/help/topic/G202131100
2. Open Kindle Create
3. Import: `curls-and-contemplation.epub`
4. Preview and adjust formatting if needed
5. Export as Kindle format (.kpf)

**Option B: Kindle Previewer (For Testing)**
1. Download: https://kdp.amazon.com/en_US/help/topic/G202131170
2. Open Kindle Previewer
3. Open: `curls-and-contemplation.epub`
4. Preview on multiple device types
5. File > Export > For publishing

**Option C: Upload EPUB Directly**
- KDP now accepts EPUB 3.0 directly!
- Upload `.epub` file and KDP will convert automatically
- Preview before publishing

## Quick Tips

### Maximize 70% Royalty
- Price between $2.99 - $9.99
- Optimal: $9.99 (highest 70% royalty price)

### KDP Select vs. Wide Distribution
**KDP Select (Exclusive):**
- ✅ 70% royalty in more countries
- ✅ Promotional tools (Free days, Countdown Deals)
- ✅ Kindle Unlimited page reads revenue
- ❌ Can't sell on other platforms for 90 days

**Wide Distribution (Non-Exclusive):**
- ✅ Sell on multiple platforms simultaneously
- ✅ Reach more readers
- ❌ 70% royalty only in select countries

### Keyword Strategy
Use all 7 keyword fields! Think about:
- What readers search for
- Problem your book solves
- Audience descriptions
- Related topics
- Specific niches
